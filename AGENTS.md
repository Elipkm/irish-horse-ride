# Instructions for the coding agent

Project: personal, single-player, realistic Irish horse riding game for iPad, delivered as a web PWA (Three.js + TypeScript + Vite).
**Read `docs/horse_game_plan.md` first.** It is the source of truth (stack, budgets, milestones, acceptance criteria).

Rules
- Work one milestone at a time (start with M1); keep the app runnable; commit after each milestone.
- Do not change the tech stack, add paid assets, or add accounts/services without asking the owner.
- Respect the performance/memory budgets in the plan; the owner tests on a real iPad and reports fps.
- Log every asset in `ASSETS.md` (source + license).
- Keep README.md up to date: run, build, deploy, install on iPad.

Layout note: this folder is the project root. Source code lives in `src/` (so the full path is `.../SariGame/src/src/`).
